# ONTAP Storage Setup

The launch form does not show run or skip switches. Leave a section blank and that task stays skipped. Enter values and that task runs. The FIPS dropdown is the exception: it defaults to false and that task runs on every launch.

Required fields are the agent, cluster management address, and password. The username defaults to admin. You can click Next and Finish with only those filled in.

Storage failover, cluster HA, cluster-management auto-revert, spare-disk zeroing, CDP, LLDP, and default broadcast-domain cleanup do not have their own fields. Every launch discovers the cluster nodes, enables storage failover on each node, and sets cluster HA only when that discovery finds exactly two nodes. It also finds the cluster management interface and enables auto-revert on it, zeros spare disks, and enables CDP and LLDP. It deletes an autogenerated Default broadcast domain when that domain is in the Default IPspace, its name starts with `Default-`, and it contains no cluster or node-management port.

Node configuration is one table. Each row is one node, so the node name is entered once. That row has separate columns for the service-processor address, data ports, aggregate name, and disk count. One aggregate is created on that node. To skip the service-processor, aggregate, interface-group, and data-port tasks, delete every row. A blank row still counts as a row, and Finish stays disabled until that row is filled in or deleted. Those same rows are the nodes used for VLANs. A VLAN is created on a node when that row lists data ports, because that is where the interface group exists.

Network Configuration holds the interface group name and mode, and the IPspace name. The interface group name defaults to `a0a`. You can change it. The mode defaults to `multimode_lacp`. The dropdown also offers `multimode` and `singlemode`. Each node that lists data ports gets that interface group, those ports are added to it, and the group MTU is set to 9000. Traffic is distributed by port. The same name and mode are used on every node. The mode is applied when the group is created. Clear the name to skip only the interface group. A blank IPspace name does not skip it. The other node-configuration tasks still run.

That same section also holds the VLAN name and VLAN ID for in-band management, NFS, iSCSI fabric A, and iSCSI fabric B. In-band management is the management VLAN. NFS is storage protocol NFS. iSCSI-A is storage protocol iSCSI on fabric A, and iSCSI-B is storage protocol iSCSI on fabric B. Leave the IPspace name blank to skip IPspace, broadcast domain, and VLAN creation. The interface group task still runs from its own name and the node data ports. Leave a network's VLAN name or VLAN ID blank to skip that network. An IPspace name on its own creates that IPspace. A VLAN name together with its VLAN ID creates a broadcast domain of that name in the IPspace. When the interface group name is set and a node row lists data ports, the VLAN interface is also created on that interface group and added to the broadcast domain. ONTAP names the interface `<interface group>-<VLAN ID>`, for example `a0a-1022`. In-band management uses MTU 1500. NFS and both iSCSI VLANs use MTU 9000. A blank interface group name, or node rows with no data ports, skips the VLAN interfaces. The broadcast domains for the filled-in networks are still created. The interface group task runs first.

Cluster name is used only by the location and timezone tasks. It must exactly match the cluster's current name. Entering a different value renames the cluster while those tasks run.

| Filled in | Task that runs |
| --- | --- |
| Cluster name and location | Update cluster location |
| Node configuration rows | Configure each node's service processor, disable flow control on its data ports, discover the disk class, and create one aggregate on that node |
| Interface group name, mode, and data ports | Create that interface group on each node that lists data ports, add those ports, and set the group MTU to 9000. The name defaults to `a0a` and the mode defaults to `multimode_lacp`. Clear the name to skip this task. A blank IPspace name does not skip it |
| IPspace name | Create that IPspace. Leave the IPspace name blank to skip IPspace, broadcast-domain, and VLAN creation. The interface group task still runs |
| IPspace name and both the VLAN name and VLAN ID for a network | Create that network's broadcast domain. In-band management uses MTU 1500. NFS uses MTU 9000. iSCSI fabric A and iSCSI fabric B each use MTU 9000. Leave that network's name or ID blank to skip it |
| IPspace name, a VLAN name and VLAN ID, the interface group name, and node rows that list data ports | Add that VLAN to the interface group on each of those nodes. Leave the interface group name blank, or list no data ports, and the VLAN interfaces are skipped |
| DNS domain and DNS servers | Configure DNS |
| NTP servers | Configure NTP |
| Cluster name and timezone | Set the timezone |
| AutoSupport mail settings | Configure AutoSupport on the nodes discovered from the cluster |
| Legacy license keys or NLF contents | Add licenses |
| FIPS dropdown | Set SSL FIPS mode on every launch. The dropdown defaults to `false`, which matches a new ONTAP cluster. Choose `true` to enable FIPS-compliant SSL |
| Any of SNMP contact, location, community, traphost, or SNMPv3 user | Configure and enable SNMP. Contact, location, and the SNMPv3 user each apply only when that field is filled, so leaving location or traphost blank does not skip the rest. Authentication and privacy are chosen independently, and both password fields stay on the form. With FIPS `false`, authentication is `none`, `md5`, `sha`, or `sha2_256` and privacy is `none`, `des`, or `aes128`. A password is required for each protocol that is not `none` when an SNMPv3 user is set. Community and traphost apply only when FIPS is `false` and that field is filled. With FIPS `true`, the form shows `sha` or `sha2_256` for authentication and `aes128` for privacy, and both passwords are required when an SNMPv3 user is set |
| Login banner text | Set the login banner |
